# Week 1 Problems

This directory contains the Week 1 Java problems.

| Problem | Source file |
| --- | --- |
| First non-repeating character | [FirstNonRepeatingCharacter.java](FirstNonRepeatingCharacter.java) |
| Palindrome checker | [PalindromeChecker.java](PalindromeChecker.java) |
| Rock-paper-scissors game | [RockPaperScissorsGame.java](RockPaperScissorsGame.java) |
| Shortest and longest word | [ShortestLongestWord.java](ShortestLongestWord.java) |
| VIP customer identifier | [VipCustomerIdentifier.java](VipCustomerIdentifier.java) |

## Compile and run

From this directory, compile a problem and run it by class name:

```bash
javac FirstNonRepeatingCharacter.java
java FirstNonRepeatingCharacter
```

Replace the filename and class name with any problem from the table above.
